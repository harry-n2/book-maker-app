## Non-Negotiable Output Rules

- Do not create a manual Markdown TOC.
- Do not insert `## 目次` into `book_full.md`.
- Use Pandoc's Word-format TOC generated by `--toc --toc-depth=3`.

- The Word TOC must be placed immediately after the body text of `はじめに`, before the next chapter heading.
- If Pandoc generated a Word `w:sdt` TOC block, move that block only.
- If local fallback conversion produced no TOC block because Pandoc is unavailable, insert an equivalent Word TOC field block in DOCX XML. Do not use Markdown TOC.
- Preserve heading-after-newline behavior in `apply_period_breaks()`. Do not remove the blank line inserted after headings.
- Do not reintroduce the expand/collapse partial-edit UI unless the user explicitly asks for it.

## Current Implementation

- `convert_to_docx()` calls Pandoc with `["--standalone", "--toc", "--toc-depth=3"]`.
- `move_word_toc_after_intro()` opens the generated `.docx`, reads `word/document.xml`, finds Pandoc's TOC `w:sdt` block by `w:instrText` containing `TOC`, and moves that block after the `はじめに` section body.
- `_make_word_toc_sdt()` is used only when no TOC block exists, usually because the local `pypandoc.py` fallback ran without a system Pandoc.
- If a page-break paragraph exists immediately before the next chapter, the TOC is inserted before that page break.
- `build_merged_md()` no longer generates or inserts a manual Markdown TOC.
