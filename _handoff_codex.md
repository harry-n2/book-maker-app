## Heading Rendering Rules

- Markdown keeps normal heading spacing only. Do not emit any visible page-start marker.
- DOCX must use custom paragraph styles: `BookTitle`, `BookTOCHeading`, `BookHeading1`, `BookHeading2`, and `BookHeading3`.
- Do not use built-in Word heading style IDs in the final document paragraphs.
- Do not use `pageBreakBefore` for these heading styles. That creates the excess whitespace seen in the current output.
- DOCX `BookTitle`, `BookTOCHeading`, `BookHeading1`, `BookHeading2`, and `BookHeading3` paragraphs must keep direct `w:spacing w:after="80"`.
- The Word TOC must use style mapping: `TOC \h \z \t "BookHeading1,1,BookHeading2,2,BookHeading3,3"`.
- Keep `w:outlineLvl` removed from the generated custom heading styles.
- Keep the partial-edit UI and `/modify-structure` API out of the codebase.

## Non-Negotiable Output Rules

- Do not create a manual Markdown TOC.
- Do not insert `## ??` into `book_full.md`.
- Use Pandoc's Word-format TOC generated by `--toc --toc-depth=3`.
- Do not remove `--toc` or `--toc-depth=3` from `convert_to_docx()`.
- The Word TOC must be placed immediately after the body text of `????`, before the next chapter heading.
- If Pandoc generated a Word `w:sdt` TOC block, move that block only.
- If local fallback conversion produced no TOC block because Pandoc is unavailable, insert an equivalent Word TOC field block in DOCX XML. Do not use Markdown TOC.
- Preserve the heading newline behavior in `apply_period_breaks()`.
- Keep the partial-edit UI removed.

## Current Implementation

- `convert_to_docx()` calls Pandoc with `["--standalone", "--toc", "--toc-depth=3"]`.
- `move_word_toc_after_intro()` opens the generated `.docx`, reads `word/document.xml`, finds Pandoc's TOC `w:sdt` block by `w:instrText` containing `TOC`, and moves that block after the `はじめに` section body.
- `_make_word_toc_sdt()` is used only when no TOC block exists, usually because the local `pypandoc.py` fallback ran without a system Pandoc.
- If a page-break paragraph exists immediately before the next chapter, the TOC is inserted before that page break.
- `build_merged_md()` no longer generates or inserts a manual Markdown TOC.
